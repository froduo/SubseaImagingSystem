【一、Windows 客户端如何开启 HEVC 硬解直转】
1) 确认硬件能解 HEVC：任务管理器 → 性能 → GPU，看是否有 “Video Decode” 引擎； 或 dxdiag 查看显卡型号。Intel 6 代(2015 Skylake) / NVIDIA Pascal(GTX10 系) / AMD Vega 及以上均支持 HEVC 硬解。
2) 安装系统级 HEVC 解码器：Microsoft Store 搜索 “HEVC”，安装 「HEVC 视频扩展」(付费约 $0.99) 或「HEVC 视频扩展(来自设备制造商)」(OEM 机型免费)； 命令行可用 winget search HEVC 定位包名。
3) 打开浏览器硬件加速：edge://settings/system → 使用硬件加速 = 开。
4) 如需要：edge://flags 搜索 HEVC，若有相关项设为 Enabled。
5) 彻底重启浏览器：任务管理器结束所有 msedge.exe 后重开(仅关窗口不够)。
6) 验证：edge://gpu → “Video Acceleration Information” 应出现 hevc main / main10；再刷新本页，「客户端 HEVC 直转」应变绿。
7) 仍不支持？多为 远程桌面(RDP)/虚拟机 场景 —— 浏览器拿不到 GPU 硬解能力， 请在物理机上直接打开；否则请使用②「通用(H.264)」转码流，或点上方「4K 实时」按钮。
8) 控制台自检：F12 执行 RTCRtpReceiver.getCapabilities('video').codecs.map(c=>c.mimeType) ，结果含 video/H265 即为支持。

【二、更简单的办法：用 VLC 看直转流】
VLC 自带 HEVC 解码，不需要安装「HEVC 视频扩展」，也不受浏览器策略限制。 直接用 VLC/mpv 打开下面「直转码流地址」里的 RTSP 链接即可 (Windows 上装 VLC 桌面版；Jetson 本机已预装 VLC 3.0.9)。

【三、服务端根治方案(推荐)】
把相机 102/103 的编码改为 H.264(相机自带编码器，不占 Jetson 资源)， 则任何客户端都能直转，彻底不依赖客户端 HEVC 能力。

【四、网页端 4K 实时显示】
① 客户端支持 HEVC 硬解 → 选「主码流 4K · H.265 直转」(服务端零编解码, 延时最低);
② 任意浏览器 → 点「4K 实时」按钮或选「主码流 4K · H.264 转码」 (Jetson NVENC 硬转, 约 16 Mbps, 需客户端能解 4K H.264)。
