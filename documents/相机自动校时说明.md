# 相机自动校时（与本地系统时间同步，偏差 < 1 秒）

## 1. 需求

热源检测图像（热像仪 HM-TD2069N-18D）与可见光图像（iDS-2ZMN2312S）需与本地系统时间自动校准，
**每次连接相机成功后自动校准一次**，且校准偏差要求 **< 1 秒**。

## 2. 接口与校准策略

| 设备 | 接口 | 认证 |
|------|------|------|
| 热像仪 `192.168.10.211` | `GET/PUT http://192.168.10.211/ISAPI/System/time` | Digest |
| 可见光 `192.168.10.212` | `GET/PUT http://192.168.10.212/ISAPI/System/time` | Digest |

**最小影响原则**：`GET` 读取设备时间文档后，**只替换其中的 `<localTime>`**，其余字段
（`timeMode` 对时模式、`timeZone` 时区、XML 命名空间）原样 `PUT` 回写。
两台设备命名空间不同（热像仪 `www.isapi.org/ver20/XMLSchema`、可见光 `www.hikvision.com/ver20/XMLSchema`），
因此必须沿用设备返回的文档结构，不能硬编码。

## 3. 校准流程（闭环迭代）

```
GET 设备时间文档(作为模板)
  ↓
第 1 轮写入：写入值 = 本机当前时间 + 补偿量(初值 0)
  ↓
读回校验：Δ = 设备时间 - 本机时间
  ↓  |Δ| > 500ms 且轮次 < 3
修正补偿量：新补偿量 = 旧补偿量 - Δ  → 进入下一轮写入
  ↓  否则
上报结果(含最终偏差)
```

补偿量的物理含义：从「取时间戳」到「设备把该值当作当前时间生效」之间的延迟
（含 HTTP 往返 + 设备内部应用时间）。该补偿量**跨连接保留**，因此第二次以后连接通常 1~2 轮即收敛。

## 4. 触发时机

| 位置 | 说明 |
|------|------|
| `MainWindow::onThermalConnectionChanged(true)` | 热像仪连接成功后延迟 1.2s 触发（等 ISAPI 链路就绪） |
| `MainWindow::onVisibleConnectionChanged(true)` | 可见光连接成功后延迟 1.2s 触发 |

结果通过 `timeSyncFinished(bool ok, const QString &info)` 回传并写入运行日志。

## 5. 实现中遇到的两个坑（均已修复）

### 5.1 首次实现 PUT 全部返回 HTTP 400

原因是 Qt 的日期格式符 `z` 表示 **毫秒**，而不是时区偏移：

```cpp
// 错误写法: 生成 "2026-09-20T18:01:47476"（缺时区偏移、毫秒直接拼接）→ 设备判定格式非法
QDateTime::currentDateTime().toString("yyyy-MM-ddTHH:mm:sszzz");
```

正确做法是按 `offsetFromUtc()` 自行拼接偏移（并用单引号转义 `T`），得到 `2026-09-21T09:27:15+08:00`。

### 5.2 只用"一次耗时补偿"精度不够（残余 1.1 秒）

设备是把收到的 `localTime` 直接当作当前时间，因此写入值必须补偿"写入→生效"的延迟。
但实测该延迟**不稳定**：可见光的 PUT 全程耗时约 1.6~2.7 秒（热像仪约 0.6 秒），
用第一轮耗时去补偿第二轮，会因两轮耗时不同而留下约 1 秒的残余偏差
（实测可见光偏快 +1.1 秒、热像仪偏慢 −0.95 秒）。

因此改为**闭环迭代**：每轮写入后读回、按实测偏差修正补偿量，直到 |Δ| ≤ 500ms 或达到 3 轮上限。

## 6. 实测结果（2026-09-21）

先把两台相机时间人为改为 `2020-01-01T00:00:00+08:00`，再启动程序观察自动校时过程：

```
热像仪校时: 第 1 轮写入 09:27:08 (补偿 0ms)
热像仪校时: 本轮偏差 -589ms, 进行第 2 轮修正
热像仪校时: 第 2 轮写入 09:27:09 (补偿 589ms)
热像仪校时成功: 已校准为 2026-09-21T09:27:09+08:00 (与本机偏差 -58 ms)      ← 2 轮收敛

可见光相机校时: 第 1 轮写入 09:27:09 (补偿 0ms)
可见光相机校时: 本轮偏差 -2981ms, 进行第 2 轮修正
可见光相机校时: 第 2 轮写入 09:27:15 (补偿 2981ms)
可见光相机校时: 本轮偏差 1506ms, 进行第 3 轮修正
可见光相机校时: 第 3 轮写入 09:27:15 (补偿 1475ms)
可见光相机校时成功: 已校准为 2026-09-21T09:27:15+08:00 (与本机偏差 -70 ms)   ← 3 轮收敛
```

独立脚本（比较设备时间与本机时间，用 GET 往返中值消除测量误差）复核：

| 设备 | 实测最大偏差 |
|------|--------------|
| 热像仪 192.168.10.211 | **0.037 秒** |
| 可见光 192.168.10.212 | **0.154 秒** |

两者均远优于 1 秒的要求。
